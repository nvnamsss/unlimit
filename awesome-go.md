## Web Frameworks

- [gin-gonic/gin](https://github.com/gin-gonic/gin) – Fast, minimalist web framework.
- [labstack/echo](https://github.com/labstack/echo) – High performance, extensible, minimalist Go web framework.
- [gofiber/fiber](https://github.com/gofiber/fiber) – Express inspired web framework.

## Database

- [go-sql-driver/mysql](https://github.com/go-sql-driver/mysql) – MySQL driver for Go.
- [lib/pq](https://github.com/lib/pq) – Pure Go Postgres driver.
- [jmoiron/sqlx](https://github.com/jmoiron/sqlx) – Extensions to database/sql.
- [gorm/gorm](https://github.com/go-gorm/gorm) – ORM library for Go.

## Testing

- [stretchr/testify](https://github.com/stretchr/testify) – Test assertions and mocks.
- [ginkgo](https://github.com/onsi/ginkgo) – BDD testing framework.
- [gotestyourself/gotest.tools](https://github.com/gotestyourself/gotest.tools) – Additional tools for testing.

## CLI

- [spf13/cobra](https://github.com/spf13/cobra) – CLI application framework.
- [urfave/cli](https://github.com/urfave/cli) – Simple, fast, and fun package for building command line apps.

## Logging

- [sirupsen/logrus](https://github.com/sirupsen/logrus) – Structured logger for Go.
- [uber-go/zap](https://github.com/uber-go/zap) – Blazing fast, structured, leveled logging.
- [rs/zerolog](https://github.com/rs/zerolog) – Zero-allocation JSON logger.

## Configuration

- [spf13/viper](https://github.com/spf13/viper) – Go configuration with fangs.
- [kelseyhightower/envconfig](https://github.com/kelseyhightower/envconfig) – Process environment variables.

## Utilities

- [mitchellh/mapstructure](https://github.com/mitchellh/mapstructure) – Decode generic map values into native Go structures.
- [google/uuid](https://github.com/google/uuid) – UUID generation.
- [pkg/errors](https://github.com/pkg/errors) – Simple error handling primitives.

## Networking

- [gorilla/websocket](https://github.com/gorilla/websocket) – WebSocket implementation.
- [valyala/fasthttp](https://github.com/valyala/fasthttp) – Fast HTTP implementation.

## Concurrency

- [golang/sync](https://pkg.go.dev/sync) – Synchronization primitives.
- [workanator/go-floc](https://github.com/workanator/go-floc) – Orchestrate goroutines with ease.

## Validation

- [go-playground/validator](https://github.com/go-playground/validator) – Struct and field validation.

## Serialization

- [json-iterator/go](https://github.com/json-iterator/go) – High performance 100% compatible drop-in replacement of "encoding/json".
- [gogo/protobuf](https://github.com/gogo/protobuf) – Protocol Buffers for Go.

## Others

- [spf13/cast](https://github.com/spf13/cast) – Safe and easy casting from one type to another.
- [pquerna/otp](https://github.com/pquerna/otp) – One-time password library.
